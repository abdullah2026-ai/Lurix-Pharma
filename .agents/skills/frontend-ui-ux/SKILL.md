# Frontend UI/UX Skill

- Follow AGENTS.md and MASTER_PROMPT.md.
- Use shadcn/ui and shared design tokens.
- Maintain consistent neumorphic surfaces with adequate contrast and visible focus rings.
- Keep POS fast, keyboard-friendly, and easy to use.
- Make cart totals, discount, and payment selection obvious.
- Ensure navigation becomes a drawer on smaller screens.
- Close the drawer using the close button, outside click, Escape, and route navigation.
- Prevent horizontal overflow at all screen sizes.
- Include loading, empty, error, success, and disabled states.
- Use toast notifications for concise feedback.
- Use confirmation dialogs for destructive actions.
- Support Bangla Unicode in user-entered fields.
- Create print styles for 58mm and 80mm thermal receipts.
- Hide application navigation and other UI when printing.
- Test keyboard navigation, form labels, touch targets, and responsive layouts.
- Do not create decorative controls without functional behavior.
