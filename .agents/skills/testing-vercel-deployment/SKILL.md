# Testing + Vercel Deployment Skill

- Run available lint, typecheck, tests, and production build.
- Fix failures rather than merely reporting them.
- Test unit conversion, weighted average cost, discount limits, gross/net profit, and Dhaka date boundaries.
- Verify permissions and unauthenticated API rejection.
- Verify POS stock decrement, insufficient-stock rejection, sale correction, and cancellation.
- Verify audit logs, expenses, reports, and CSV validation.
- Check 58mm/80mm receipt print layouts.
- Test mobile, tablet, and desktop for horizontal overflow and unusable dialogs.
- Document Firebase Console and MongoDB Atlas setup.
- Document local .env.local and Vercel environment variables.
- Never commit real credentials or service-account JSON.
- Report exactly which checks ran and which integrations still require credentials.
- Never claim successful deployment without verification.
